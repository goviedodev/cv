## Proyecto Público Destacado

**Aplicación de reporte de turnos — Next.js 14 + NestJS** — [github.com/goviedodev/niuro](https://github.com/goviedodev/niuro)

Aplicación full stack que diseñé y construí para reemplazar una planilla de operaciones industriales por una app web estructurada y trazable.

- Frontend en Next.js 14 (App Router) con React 18 y TypeScript: sesión de usuario, formularios controlados con componentes reutilizables y un wrapper `fetch` tipado que normaliza los errores de validación por campo.
- Backend en NestJS 10 + TypeScript (Node.js) consumido vía APIs REST, arquitectura por capas, `ValidationPipe` global y pruebas unitarias en Jest.
- Autenticación con JWT y dos roles; la autoría de cada registro se toma del token, nunca del formulario.
- Builds Docker multi-stage y el mismo pipeline de CI/CD implementado en GitHub Actions y Azure Pipelines.
