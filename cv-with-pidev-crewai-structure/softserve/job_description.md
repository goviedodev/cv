## About the role

Build modern full-stack solutions that help a global Energy, Oil & Gas client accelerate digital transformation initiatives. Working with a distributed team across the US and Ukraine, develop scalable applications that optimize geophysical workflows, improve automation, and deliver reliable cloud-based solutions supporting critical business operations.

## Responsibilities

- Design and develop full-stack applications using React, Next.js, Python, and GraphQL to deliver scalable, business-critical solutions.
- Drive ownership of application features from design through deployment, ensuring performance, maintainability, quality, and production readiness.
- Collaborate closely with architects, data scientists, DevOps engineers, QA specialists, and business stakeholders.
- Develop and integrate backend services, APIs, and data processing components supporting secure and reliable platform capabilities.
- Translate business requirements into scalable technical solutions while contributing to application architecture and engineering best practices.
- Implement automated testing strategies, troubleshoot production issues, and optimize application performance across frontend and backend.
- Support deployment, monitoring, and continuous improvement of cloud-based applications running on AWS and modern development pipelines.
- Contribute to technical discussions, knowledge sharing, and continuous improvement within an Agile, cross-functional engineering team.

## Requirements

- Strong experience with full-stack development.
- 5+ years working within Agile software development teams.
- Hands-on expertise with React, Next.js, modern JavaScript, TypeScript, and Python.
- Practical experience developing APIs and backend services, including GraphQL, authentication and authorization mechanisms, and database design using relational and/or NoSQL technologies.
- Solid knowledge of software engineering principles, object-oriented programming, automated testing, troubleshooting, and application performance optimization.
- Familiarity with cloud-native development on AWS or similar cloud platforms; Docker and CI/CD pipelines an advantage.
- Experience translating business requirements into scalable technical solutions while collaborating with cross-functional teams.
- Practical experience using AI-assisted development tools such as GitHub Copilot or Claude Code is a plus.
- Upper-intermediate English level (written and spoken), collaborating within the US timezone.
