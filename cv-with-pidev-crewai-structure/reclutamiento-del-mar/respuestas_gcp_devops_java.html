DevOps

Ciclo completo

Manejo el ciclo de despliegue de punta a punta, no solo una etapa puntual:

  • IaC con Pulumi: cómputo, red, IAM y secretos de Te Llevo App versionados como código.
  • CI/CD: GitLab (Seven IT, Te Llevo App), Jenkins y Azure DevOps (Citibank).
  • Contenedores y despliegue: Docker y Cloud Run en producción.
  • Seguridad de infraestructura: WAF y Load Balancer mantenidos como código junto al resto del stack.

Un diferenciador que quiero destacar: uso IA de forma intensiva dentro del flujo DevOps — no solo para escribir código, sino para investigar mejores prácticas, comparar alternativas de arquitectura y llegar más rápido a la mejor solución disponible para un problema dado. Acelera tanto el diagnóstico como la implementación.
