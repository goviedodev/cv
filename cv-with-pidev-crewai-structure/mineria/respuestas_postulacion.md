# Respuestas de postulación — 2Brains / Senior Full Stack Developer (Minería, React/Next.js/NestJS)

## a) Cuéntanos sobre tu experiencia y perfil profesional.

Soy full-stack developer con 15+ años construyendo aplicaciones completas de punta a punta —backend, frontend, base de datos e infraestructura— en más de un stack: Java/Spring Boot, PHP, Elixir/Phoenix y Node.js/TypeScript.

El respaldo más directo para este rol es un proyecto público que diseñé y construí: [github.com/goviedodev/niuro](https://github.com/goviedodev/niuro), una aplicación en Next.js 14 (App Router) + React 18 + TypeScript en el frontend, con backend en NestJS 10 + TypeScript, que reemplaza una planilla de operaciones industriales (incidentes de turno, detenciones, observaciones de seguridad) por vistas estructuradas y trazables, con autenticación JWT por roles y **exportación de datos a un data lake de Databricks vía Files API (Unity Catalog Volumes)**. Es el mismo tipo de problema que resuelve un visualizador de indicadores de condición y riesgo de activos —consolidar información dispersa en vistas de consulta navegables, desde lo global al detalle— aplicado a otro dominio operacional.

Antes lideré de punta a punta un sistema de gestión clínica (Seven IT SpA) para una clínica que atiende a la operación minera y química de SQM: backend REST, interfaz web, esquema PostgreSQL y despliegue, con un equipo de 4 desarrolladores a cargo. En Citibank migré una base de datos financiera de Sybase a Oracle —más de 15 millones de registros, sin pérdida de datos— bajo un proceso regulatorio estricto junto a equipos de EE. UU., Ucrania e India. Actualmente diseño y opero la arquitectura completa de una plataforma de movilidad en producción sobre Google Cloud, con Pulumi como infraestructura como código.

Trabajo también con IA aplicada al desarrollo (Claude Code como herramienta principal) para acelerar testing y documentación, siempre con la suite de pruebas automatizadas como puerta de calidad antes de cualquier cambio.

Después de 15 años construyendo sistemas completos desde cero, más de una vez y en más de un lenguaje, la brecha técnica entre una tecnología puntual u otra pesa menos que haber resuelto ya estos mismos problemas de arquitectura, datos y producción bajo presión real.
