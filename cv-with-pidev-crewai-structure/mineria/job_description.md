## Sobre el empleo

Buscamos Full Stack NestJS/Next.js con experiencia en dashboards operacionales de indicadores (no solo CRUD web) para importante cliente de Minería.

### Objetivo del rol

Buscamos un/a Desarrollador Full Stack para construir la plataforma web del Visualizador de Riesgos de Mantenimiento, habilitando la consulta consolidada de la condición y desempeño de los activos, con navegación desde una visión global hacia el detalle del activo o componente.

### Responsabilidades

- Desarrollar APIs y servicios backend para disponibilizar la información integrada.
- Desarrollar la interfaz web y las vistas de consulta, con navegación desde vista global a detalle de activo/componente.
- Elaborar y validar mockups y prototipos junto a usuarios de operación, mantenimiento y confiabilidad.
- Implementar autenticación, autorización y control de accesos según estándares corporativos.
- Habilitar la visualización de la evolución histórica de variables e indicadores.
- Construir dashboards operacionales para consulta de indicadores de condición y riesgo.
- Integrar el frontend con servicios de datos provenientes de Databricks.

### Requerimientos del cargo

**Requisitos académicos:** Título Profesional: Ingeniero(a) Ejecución, Civil, Informática, Computación o carrera afín (títulos extranjeros: 8 semestres mínimo + convalidación/apostilla formal en Chile).

**Experiencia laboral requerida:**
- Más de 5 años en desarrollo de sistemas web.
- Más de 4 años en el stack corporativo: NestJS/Node.js (backend) y Next.js/React (frontend).
- Experiencia comprobable en desarrollo de dashboards y vistas operacionales para consulta de indicadores, con navegación desde visión global al detalle del activo.
- Experiencia integrando frontend con fuentes de datos tipo Databricks/Data Lake.

**Stack tecnológico**

Must-have: Node.js 20+, NestJS, TypeScript, Next.js 15+, React, Git / Azure DevOps.
Seguridad: Microsoft Entra ID (OAuth2/OIDC), Azure Key Vault.
Deseables: experiencia integrando aplicaciones web con Azure Databricks o Data Lake; certificaciones en Node.js, NestJS, React o Next.js.
