## Qué es el trabajo

Conversar con el modelo sobre tareas de ingeniería de software y escenarios técnicos **usando
Python**, verificando exactitud, evaluando calidad de código, documentando casos de error y
entregando feedback para mejorar el entrenamiento y las métricas de evaluación del modelo.
