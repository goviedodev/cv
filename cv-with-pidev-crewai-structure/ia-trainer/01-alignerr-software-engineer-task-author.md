## Qué es el trabajo

No es anotar datos. Es **escribir las tareas con las que se entrena y evalúa a los agentes de
código**. Diseñas escenarios realistas de ingeniería (fallos de integración, debugging sobre
logs, trazas de bugs a través del código fuente), defines la rúbrica de qué cuenta como
solución correcta, montas el entorno con codebase y estado de sistema reales, y **resuelves tú
mismo cada tarea** para validar que es correcta y solucionable.

## Responsabilidades

- Redactar prompts de tareas de ingeniería realistas: fallos de integración, debugging basado
  en logs, trazado de bugs a través del código fuente.
- Desarrollar rúbricas de puntuación que definan la solución correcta y cómo verificarla.
- Construir entornos de tarea con codebases y estados de sistema auténticos.
- Resolver personalmente cada tarea para garantizar su validez.
- Ajustar la dificultad para que la tarea desafíe al modelo en el nivel adecuado.
- Revisar y refinar material de tareas generado por IA.

## Requisitos

- Ingeniero de software **en activo**, con experiencia de debugging a nivel producción.
- Dominio de Git y control de versiones.
- Capacidad fuerte de análisis de logs y trazado de fallos.
- Conocimiento de infraestructura, APIs y sistemas CI/CD.
- Capacidad de implementar y validar soluciones de código.
- Capacidad de establecer estándares medibles de corrección.
- **No se requiere background en machine learning.**
