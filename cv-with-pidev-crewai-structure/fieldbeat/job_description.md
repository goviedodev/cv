## Descripción

FieldBeat optimiza el trabajo en terreno para cientos de empresas en Latinoamérica (gestión de equipos móviles, captura de datos críticos, digitalización de operaciones). El rol se integra al "motor" central: una **API REST de alto rendimiento sobre Java y Undertow** que procesa más de **100 millones de requests mensuales**, sobre infraestructura cloud en Microsoft Azure (Blob Storage, Tables, NoSQL). Construyen bajo metodología Spec-Driven Development (SDD) e integran activamente agentes de IA en el flujo de ingeniería.

## Funciones

- Desarrollo de API Core: diseñar, implementar y evolucionar endpoints REST en Java (8+) sobre arquitecturas ligeras de alta velocidad (Undertow).
- Persistencia Cloud & NoSQL: modelar y optimizar almacenamiento semi-estructurado en Azure Storage (Tables y Blobs).
- Alta Concurrencia y Rendimiento: optimizar consumo de memoria, serialización JSON y manejo eficiente de hilos para tráfico masivo.
- Desarrollo Asistido por IA: usar herramientas y agentes de IA generativa como parte natural del flujo diario para acelerar entrega y análisis.
- Calidad y Resiliencia: buenas prácticas de arquitectura, manejo robusto de excepciones, observabilidad y seguridad en las APIs.

- Ecosistema Cloud: Azure deseable, o sólida experiencia en AWS/GCP con alta capacidad de transferencia técnica.
- Residencia obligatoria en la Región Metropolitana (Santiago de Chile), disponibilidad híbrida.
