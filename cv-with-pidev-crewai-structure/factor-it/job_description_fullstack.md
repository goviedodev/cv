## Descripción

En Factor IT buscan un/a Full Stack Senior Developer para integrarse a un proyecto estratégico relacionado con **Checkout, medios de pago y pasarelas de pago**, participando en la evolución de canales digitales y experiencias transaccionales. Buscan una persona con autonomía técnica, capacidad para resolver problemas complejos y facilidad para trabajar colaborativamente con equipos multidisciplinarios.

## Funciones

- Diseñar y desarrollar soluciones Full Stack que integren frontend, backend, APIs y servicios externos.
- Desarrollar interfaces y componentes reutilizables utilizando React y TypeScript.
- Construir servicios y APIs backend utilizando Node.js, aplicando buenas prácticas de desarrollo.
- Participar en el diseño e implementación de arquitecturas basadas en microfrontends.
- Diseñar y desarrollar integraciones con APIs REST y servicios externos.
- Participar en el desarrollo de funcionalidades asociadas a Checkout, medios de pago y flujos transaccionales.
- Construir componentes bajo sistemas de diseño (Design Systems), asegurando consistencia visual y funcional.
- Participar en el ciclo completo de desarrollo: refinamiento de historias de usuario, desarrollo, pruebas, code review y despliegue.
- Desarrollar pruebas unitarias y de integración.
- Participar en procesos de Merge Request y CI/CD utilizando GitLab.
- Analizar y resolver bugs de distinta complejidad, realizando refactorizaciones cuando sea necesario.
- Participar en la evolución de plataformas digitales y CMS headless como Modyo.
- Colaborar con equipos técnicos, funcionales y de producto.
- Aplicar buenas prácticas de seguridad, calidad, versionamiento y mantenibilidad.

- Profesional en Ingeniería de Sistemas, Ingeniería Informática, Computación o carreras afines.
- 4 años o más de experiencia en desarrollo Full Stack.
- Experiencia sólida con React y TypeScript.
- Experiencia en desarrollo backend con Node.js.
- Experiencia desarrollando e integrando APIs REST.
- Conocimientos de arquitecturas de microfrontends.
- Experiencia trabajando con componentes reutilizables y Design Systems.
- Experiencia utilizando Git y herramientas de CI/CD; experiencia con GitLab CI/CD.
- Conocimientos de bases de datos relacionales y/o NoSQL.
- Experiencia trabajando bajo metodologías ágiles como Scrum.

**Conocimientos técnicos requeridos:** React, TypeScript, JavaScript, Node.js, APIs REST, Microfrontends, Arquitectura de aplicaciones web, Integración de servicios y APIs, Git, GitLab CI/CD, Testing y buenas prácticas, componentes reutilizables y Design Systems, bases de datos relacionales y/o NoSQL.
