## Misión del rol

Como Cloud Engineer, responsable **end-to-end** de mejorar, optimizar y monitorear la infraestructura, asegurando las plataformas internas que usan los equipos de desarrollo para moverse rápido y sin fricción. No buscan a alguien que solo "mantenga la nube funcionando" — buscan alguien proactivo que implemente, asegure y lleve el ecosistema al siguiente nivel de principio a fin, combinando la rigurosidad del cumplimiento de seguridad con la curiosidad de la Inteligencia Artificial.

## Funciones — tres pilares estratégicos

### 1. Arquitectura Serverless y Automatización

- Diseñar y evolucionar arquitecturas serverless en AWS (Lambda, API Gateway, SQS, SNS) para nuevos servicios y para ir reemplazando el monolito.
- Automatizar ciclos de despliegue con IaC y GitHub Actions para acelerar la entrega de software.
- Crear templates reutilizables de IaC y pipelines para que cada equipo los adopte sin depender de una sola persona.
- Investigar y desplegar automatizaciones basadas en agentes de IA para optimizar procesos internos y eliminar tareas manuales.

### 2. Seguridad Cloud y Platform Engineering

- Ser dueño/a de la seguridad de la infraestructura: detección de tráfico anómalo, gestión de secretos, IAM y respuesta ante incidentes.
- Construir herramientas y plataformas internas para que los equipos de desarrollo se autogestionen (ej.: crear un repo o una API con el estándar ya aplicado, en un par de clics).
- Implementar y auditar políticas de gobernanza de forma autónoma, no solo en el papel.

### 3. Observabilidad, Confiabilidad y Costos

- Mantener sistemas de monitoreo y alertas con CloudWatch, Grafana u otras herramientas, con foco en detección proactiva, no reactiva.
- Participar en la resolución de incidentes con cultura post-mortem: causa raíz y prevención, no parches.
- Monitorear costos de forma continua y actuar como referente técnico, empoderando a los equipos de desarrollo en el uso óptimo de AWS.
